## How this audit was done, and its limits

This session's network egress is restricted to GitHub, npm/PyPI-class registries, and a few other allow-listed hosts. Direct requests to `www.akintilo.com` and `preview.akintilo.com` were blocked by the environment's proxy (`EGRESS_BLOCKED`), so **the live Adobe Portfolio site and the live preview were not fetched or re-verified in this session.** Where the task asked for a live side-by-side comparison, this document instead relies on:

- `site/README.md` and `site/design-qa.md` in `akintilo-portfolio`, which record an earlier, in-browser comparison against a "user-selected Option 1 screenshot" of the Adobe site (dated September 13, 2026) and confirm the migration already captured the Adobe project list (19 projects imported, 17 published).
- The structured content in `site/content/projects/*.json` and `site/content/settings.json`, which is the current system of record for the target repo.
- `web-portfolio`'s `llms.txt`, `portfolio.html`, and its per-case-study HTML pages, which describe an independently-redesigned personal site built from the same underlying career history, plus a large library of original media in `web-portfolio/images/`.

**Recommendation:** before Phase 3 QA, someone with browser access to `https://www.akintilo.com` and `https://preview.akintilo.com` (Ayodeji or ChatGPT) should do one direct side-by-side pass to confirm nothing has changed on the Adobe site since the September 13 reference screenshot, and to sanity-check the preview against this document's findings.

### `work.akintilo.com`-hosted — migrated to local media, 2026-10-09

19 video files across 5 project JSON files were previously referenced by absolute URL to `work.akintilo.com`. All 19 are now self-hosted in `site/public/media/`:

- `brand-systems-and-web-performance.json` — 5 Secureframe + 4 AppOmni videos → `motion-secureframe-{01,06,08,09,10}.mp4`, `motion-appomni-{01,02,03,04}.mp4`
- `docusign-enterprise-campaign.json` — 1 video → `motion-docusign.mp4`
- `event-brand-experiential.json` — 4 videos → `motion-navan-events-hero.mp4`, `motion-mongodb-events-{01,02,03}.mp4`
- `lufthansa.json` — 1 video → `motion-lufthansa-hero.mp4`
- `tripactions.json` — 4 videos → `motion-tripactions-travel-expense-hero.mp4`, `motion-tripactions-ad-{1,2,3}.mp4`

Went with **option 2** from the three previously documented here (re-compress and commit, rather than keep external or move to a paid external host) — Ayodeji asked to migrate all 19, not a selected subset. Each was re-encoded from the `web-portfolio/images/` originals: H.264, width capped at 1920px (none exceeded it), audio stripped (every one of these blocks renders `autoplay muted loop` — none sets `playback: "controls"` — so the audio track was always inaudible dead weight), `+faststart` for progressive playback. 132 MB of originals → 54 MB. Integrity verified via `ffmpeg -f null` full-decode pass (zero errors, durations match source) and extracted-frame spot checks on 3 files, confirming correct visual content. Real `<video>` playback could not be verified in this session's headless Chromium — that specific build has no H.264 decode support at all (confirmed via `canPlayType` returning `''` for H.264 regardless of source file, so this is a sandbox limitation, not a property of these files), but H.264/MP4 is the same codec the originals already used and is universally supported in real browsers.

## Gallery layout audit

As of 2026-09-20, every one of the then-19 projects' `gallery` blocks used the default `layout: "bento"` (no project set an explicit `layout` field). `src/App.jsx`'s `BentoGallery` component computes column spans from each image's aspect ratio (or an editor-set `small/medium/large/wide` size) and packs rows densely — this is a real, working masonry, not a placeholder. The CSS also defines `.gallery.layout-uniform` selectors for narrow breakpoints, but no component set `layout: "uniform"`, so that mode was effectively unused.

**Update 2026-10-01:** two projects now explicitly set `layout: "justified"` — `mongodb-the-next-generation-database` (the original prototype, converted from bento) and `meta-connect` (built justified from creation, since it's new content rather than a bento conversion). The remaining 18 published projects are still bento and untouched. The `JustifiedGallery` component and its click-to-open, keyboard-accessible lightbox (see `docs/portfolio-decisions.md`) are shared code — `meta-connect` uses the exact same component as the original prototype, not a copy.
